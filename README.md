# 📊 Data Analyst Nanodegree Projects

This repository contains the main projects I completed during my **Udacity Data Analyst Nanodegree**. Each project applies the data analysis process: gathering, assessing, cleaning, exploring, and communicating insights using Python and its key libraries.

---

## 🏥 Project 1: Investigate a Dataset – *Medical Appointment No-Shows*

- **Objective:** Analyze why patients miss scheduled medical appointments in Brazil.
- **Dataset:** [No-show appointments dataset (Kaggle)](https://www.kaggle.com/datasets/joniarroba/noshowappointments)
- **Key Questions:**
  - Do medical conditions (e.g., hypertension, diabetes) influence no-show rates?
  - Does the number of days between scheduling and appointment affect attendance?
- **Skills Used:** `Pandas`, `Matplotlib`, `Seaborn`, Data Cleaning
- **Result:** Identified trends that link health conditions and scheduling gaps to patient attendance.

---

## 🧼 Project 2: Data Wrangling – *Car Sales vs. Fuel Prices*

- **Objective:** Assess if car sales are influenced by changes in fuel prices over time.
- **Datasets:**
  - Car sales data from [DVM Car Listings](https://www.kaggle.com/datasets/mexwell/dvm-car)
  - Fuel price data manually gathered from multiple online sources
- **Wrangling Methods:**
  - Used Kaggle API and manual data import
  - Cleaned missing values, formatted dates, merged datasets
- **Skills Used:** `Pandas`, `Kaggle API`, `Data Cleaning`, Merging Datasets
- **Result:** Discovered patterns showing a slight inverse relationship between fuel prices and specific vehicle sales.

---

## 🚲 Project 3: Communicate Data Findings – *Ford GoBike Exploratory Data Analysis*

- **Objective:** Visualize and explain key usage trends in San Francisco’s bike-sharing program.
- **Dataset:** [Ford GoBike System Data](https://www.fordgobike.com/system-data)
- **Visualizations:**
  - Univariate, bivariate, and multivariate plots
  - Analysis by user type, trip duration, and time of day
- **Skills Used:** `Matplotlib`, `Seaborn`, storytelling with data
- **Result:** Identified peak hours, differences between subscriber and casual users, and popular travel durations.
